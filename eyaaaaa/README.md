# Ujian Akhir Semester
Lengkapi program ini dengan ketentuan sebagai berikut:  
- Pengguna melakukan registrasi pada form registerUser.html, bila proses registrasi berhasil akan redirect ke /success/<namapengguna>
- Pengguna melakukan login pada from loginform.html dengan memasukan username dan password yang sudah teregistrasi pada database. Bila proses registrasi berhasil akan redirect ke /success/<namapengguna>
- Setiap form input harus menggunakan style yang telah disiapkan (styles.css)

Hint :
- Eksekusi script python UserRegistration.py untuk menjalankan backend.
- Untuk melihat data mahasiswa yang ada pada database, silahkan mengakses link http://127.0.0.1:5000/userlist. Untuk mengakses link tersebut, pastikan Flask telah dijalankan.  
- form login dan register user dapat dilihat dengan membuka loginform.html dan registerUser.html pada browser
